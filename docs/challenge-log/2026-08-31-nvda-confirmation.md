# Challenge Log — NVDA Post-Earnings Confirmation

## Challenge
The prior HIGH assessment relied in part on earnings confirmation, sector confirmation, and sustained price confirmation. A strong post-earnings session was treated as evidence of price confirmation.

## New contradictory observation
The report records a material Friday reversal after the post-earnings rally. This weakens the assumption that one strong session is sufficient evidence of durable price confirmation.

## Challenge result
**Keep the contradiction visible. Do not backfill or rationalize the prior HIGH state.** Record the state transition and preserve the evidence that caused it.

## Proposed experimental change
Test a post-event confirmation condition requiring:
- earnings/event confirmation;
- a 2–3 session hold above the defined post-event breakout zone; and
- supportive relative volume.

## Validation requirement
Before promotion to production:
- define the breakout-zone calculation precisely;
- define the relative-volume calculation precisely;
- run the rule against historical post-event observations;
- measure false confirmations and missed confirmations;
- compare results with the existing one-session condition;
- version the rule and retain both outcomes.

## Production status
**Not yet a production rule.**
